# mace-man 3D Builder

[![English](https://img.shields.io/badge/Language-English-blue.svg)](README.md)
[![日本語](https://img.shields.io/badge/Language-日本語-green.svg)](README-jp.md)

Microsoft 3D Builder と同等の機能を持った、ブラウザ完全ローカル動作型の簡易3Dモデル編集ツール「mace-man 3D Builder」です。  
外部ネットワーク通信を一切行わず、ローカル環境だけで高速・安全に動作します。

---

## 🌟 特徴

- **完全オフライン動作**: 外部CDNや外部APIへの通信は一切発生しません。すべての3Dレンダリング、演算、ファイル読み書きがブラウザ内で完結します。
- **直感的な操作性（Fluent Design）**: Windows 11 / 3D BuilderライクなクリーンなUI。
- **言語切り替え機能**: 画面右上のセレクターから **日本語 🇯🇵 / 英語 🇺🇸** を瞬時に切り替え可能（設定はブラウザに自動保存）。
- **高度なメッシュ編集**:
  - **ブーリアン演算**: 結合（Union）、型抜き（Subtract）、交差（Intersect）
  - **平面切断（Split）**: 任意の高さ・角度でメッシュをきれいにスライス（上/下/両方保持、切断面の自動穴埋め）
  - **接地（Lay Flat）**: 底面を床面（Y=0）にピタッと合わせる
  - **整列（Align）**: 複数オブジェクトをX/Z軸で中央揃え
- **多彩なファイル形式に対応**:
  - **読み込み（ドラッグ＆ドロップ対応）**: STL, OBJ, 3MF, GLTF/GLB, PLY
  - **書き出し**: STL（バイナリ）, 3MF, OBJ, GLB, PLY

## 🚀 起動方法

### 💡 ワンクリック起動（推奨）
初回依存パッケージのインストールからローカルサーバー起動、ブラウザの自動オープンまでを自動で行うスクリプトを用意しています。

- **Windows（バッチファイル）**:  
  エクスプローラーで **`start.bat`** をダブルクリックするだけです。
- **Windows（PowerShell）**:  
  ```powershell
  .\start.ps1
  ```
- **macOS / Linux / Git Bash（シェルスクリプト）**:  
  ```bash
  chmod +x start.sh  # 初回のみ実行権限付与
  ./start.sh
  ```

---

### 💻 手動コマンド起動

#### 必要環境
- **Node.js**: v18.0 以上（推奨: v20+ / v24+）
- **npm**: v9.0 以上

#### 1. 初回依存関係インストール
プロジェクトのルートディレクトリで以下を実行します：

```bash
npm install
```

> **Note (Windows環境)**: PowerShellでスクリプトの実行ポリシー制限（`UnauthorizedAccess`）が出る場合は、`npm.cmd install` を使用するか、管理者権限のターミナルで `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` を実行してください。

#### 2. ローカルサーバー起動
以下のコマンドで開発サーバーを起動します：

```bash
npm run dev
```

起動後、ターミナルに表示されるURLをブラウザ（Chrome, Edge, Firefox等）で開きます：
```
http://localhost:3000/
```

### 3. 本番用ビルド（静的ファイル生成）
配布用・静的ホスティング用のビルドを行う場合：

```bash
npm run build
```
生成された `dist/` フォルダ内のファイルをローカルWebサーバー等に配置することで、単体でも動作します。

## 🎮 主な機能と操作ガイド

### 1. 視点操作（カメラ）
- **回転（オービット）**: マウス左ボタンドラッグ
- **平行移動（パン）**: マウス右ボタンドラッグ
- **ズーム**: マウスホイール
- **視点プリセット**: 「表示」タブ内の「上面」「前面」「右側面」「等角」「全体表示」ボタンで視点を一発切り替え

### 2. オブジェクトの挿入
「挿入」タブから以下の基本プリミティブをワンクリックで追加できます。  
すべてのオブジェクトは**床面（Y=0）に底面がぴったり接地**して生成されます。
- 立方体 (Cube)
- 円柱 (Cylinder)
- 球体 (Sphere)
- 円錐 (Cone)
- 角錐 (Pyramid)
- トーラス (Torus / ドーナツ型)
- 六角柱 (Hexagonal Prism)
- くさび (Wedge)

### 3. トランスフォーム（変形・寸法変更）
- **3Dギズモ**: 画面中央下のモードバーまたはショートカットキーで切り替え
  - `W`: 移動モード
  - `E`: 回転モード
  - `R`: 拡大縮小モード
- **寸法指定（右側インスペクター）**:
  - 幅（W）、高さ（H）、奥行（D）をミリメートル（mm）単位で直接数値入力可能
  - 「比率維持」チェックボックスで縦横比を固定したままスケーリング可能
- **接地（Lay Flat）**:
  - オブジェクトを回転させた後でも、クイックツールバーまたは「編集」タブの「接地」をクリックすると、最下部が床面にピタッと着地します。

### 4. ブーリアン演算（結合・型抜き・交差）
複数のオブジェクトを選択（`Shift` キーまたは `Ctrl` キーを押しながらクリック）した状態で、「編集」タブから実行します：
- **結合 (Merge / Union)**: 複数のオブジェクトを融合し、内部ポリゴンをきれいに除去
- **型抜き (Subtract)**: 最初に選択した基準オブジェクトから、重なっている部分をくり抜く
- **交差 (Intersect)**: 重なり合っている体積部分だけを残す

### 5. 平面切断・スライス（Split）
1. 切断したいオブジェクトを選択し、「編集」タブの「分割 (Split)」をクリック
2. 画面上に半透明の切断平面が現れます
3. スライダーで切断高さ（Y位置）や角度（チルト）を調整
4. 「上側を残す」「下側を残す」「両方を保持」から選択して「切断を実行」をクリック
5. 切り口は自動的にポリゴンでフタ（Cap）され、ソリッドな立体が維持されます

### 6. メッシュ単純化（Simplify）
Microsoft 3D Builder の「単純化」と同様に、モデルの外観を保ちながら頂点数・面数を削減（デシメーション）してファイルサイズを軽量化できます。
1. 対象オブジェクトを選択し、「編集」タブの「単純化」をクリック
2. 画面上部に単純化コントロールバーが表示されます
3. スライダー（0〜6）を操作して削減度を調整します：
   - **0 (一番左)**: 変更なし（元の頂点数）
   - **1〜5**: 段階的に頂点・ポリゴン面を削減（3Dモデル上にリアルタイムでプレビュー反映）
   - **6 (一番右)**: 最も単純化（安全に形状を維持しつつ最大削減）
4. **「決定」ボタン**（または `Enter` キー）で確定（履歴に追加され `Ctrl+Z` で取り消し可能）
5. **「キャンセル」ボタン**（または `Esc` キー）で元の状態に戻して終了

### 7. エンボス・浮き彫り/型抜き（Emboss）
Microsoft 3D Builder の「エンボス」と同様に、モデルの表面にテキストや図形、画像を浮き彫り（凸）または彫り込み（凹 / 型抜き）できます。
1. 対象オブジェクトを選択し、「編集」タブの「エンボス」をクリック
2. 画面上部にエンボス設定バーが表示され、モデル表面にプレビュー立体が配置されます
3. 設定項目：
   - **モード**: 「エンボス (凸)」で浮き彫り、「型抜き (凹)」で彫り込み
   - **タイプ**:
     - **テキスト**: 任意の文字列（日本語、英数、記号）、フォント選択（メイリオ、游ゴシック、Arial、Segoe UI、Impact等）、太字・斜体
     - **シェイプ**: 星、ハート、円、四角、六角形、矢印、チェック、スマイルなどのプリセット形状
     - **画像**: PNG、JPEG、SVGなどのカスタム画像を読み込んで3Dエンボス化（反転オプション対応）
   - **深さ・サイズ**: スライダーで押し出し深さ（mm）や全体サイズ（mm）をリアルタイム調整
   - **面スナップ**: 「上」「前」「後」「左」「右」「底」ボタンで、モデルの各面にワンクリックで吸着・配置
   - **3Dギズモ操作**: ビューポート上でエンボスオブジェクトをマウスドラッグして自由に移動・回転・拡縮可能
4. **「適用」ボタン**（または `Enter` キー）でブーリアン演算を実行して確定（`Ctrl+Z` で元に戻せます）
5. **「キャンセル」ボタン**（または `Esc` キー）で中断

### 8. ファイルの読み込み・保存
- **開く（インポート）**: 「ファイル」タブの「開く」ボタン、または3Dビューポートへの直接**ドラッグ＆ドロップ**
- **保存（エクスポート）**: 「ファイル」タブから「STL出力」「3MF出力」「OBJ出力」「GLB出力」「PLY出力」を選択（3Dプリンタ用には「STL出力」または「3MF出力」が最適です）

### 8. ショートカットキー一覧
| キー | 操作 |
| :--- | :--- |
| `W` | 移動ギズモ |
| `E` | 回転ギズモ |
| `R` | 拡大縮小ギズモ |
| `Delete` / `Backspace` | 選択オブジェクトの削除 |
| `Ctrl` + `D` | 選択オブジェクトの複製 |
| `Ctrl` + `Z` | 元に戻す (Undo) |
| `Ctrl` + `Y` (または `Ctrl`+`Shift`+`Z`) | やり直す (Redo) |
| `Shift` + クリック | 複数選択 / 選択解除 |
| `Enter` | 単純化の決定 |
| `Esc` | 単純化のキャンセル |

## 🖥️ デスクトップGUIアプリ（Electron）の実行とビルド

本ツールはブラウザ版に加えて、**Electron** によるネイティブGUIデスクトップアプリケーション（Windows / Mac / Linux）に対応しています。

### 1. 開発モードで起動
```bash
npm run electron:dev
```
Vite開発サーバーとElectronウィンドウが連携して起動します。

### 2. 実行ファイルのビルド

各OS向けの実行ファイルは `release/` ディレクトリに出力されます。

- **Windows用実行ファイル（.exe）のビルド**:
  ```bash
  npm run build:win
  ```
  - `release/mace-man 3D Builder Setup 1.1.4.exe`（NSISインストーラー）
  - `release/mace-man 3D Builder 1.1.4.exe`（インストール不要のポータブル実行ファイル）

- **Linux用実行ファイルのビルド**:
  ```bash
  # Windowsホスト上からビルドする場合（展開・実行可能なzipアーカイブ）
  npm run build:linux:zip

  # Linux環境でAppImageやdebを出力する場合
  npm run build:linux
  ```
  - `release/mace-man-3dbuilder-1.1.4.zip`

- **macOS用実行ファイル（.dmg / .zip）のビルド**:
  ```bash
  npm run build:mac
  ```
  *(※macOS向けビルドはAppleの規約およびツールの関係上、macOS環境または後述のGitHub Actions CIから出力します)*

### 3. GitHub Actions による全OS自動ビルド＆リリース
`.github/workflows/build.yml` を同梱しているため、リポジトリをプッシュまたは `v1.1.4` などのタグを作成するだけで、GitHub上の Windows / macOS / Linux ランナーが並列で実行ファイルを自動ビルドし、GitHub Releases へ即座に配布バイナリをアップロードします。

## 📝 更新履歴

### v1.1.4
- **Microsoft 3D Builder 仕様の「エンボス (Emboss)」機能の新設**:
  - モデル表面にテキスト、プリセットシェイプ（星、ハート、矢印など）、カスタム画像（PNG、JPEG、SVG）を浮き彫り（凸）または彫り込み（凹 / 型抜き）できるエンボスツールを「編集」タブに追加。
  - テキストは日本語（漢字・かな・英数字・記号）、各種フォント、太字・斜体に完全対応。
  - Marching Squares 等値線追跡と Shoelace 符号付き面積判定により、文字のくり抜き穴（「A」「B」「日」「国」等の内側）も含めて正確で水密な 3D 押し出しメッシュを生成。
  - 押し出し深さ（Depth）、全体サイズ（Size）、面スナップ（上・前・後・左・右・底）、3Dギズモによるインタラクティブな移動・回転・拡縮に対応。
  - `BufferGeometryUtils.mergeVertices` による重複頂点マージを導入し、CSG ブーリアン結合（Union）および型抜き（Subtract）の安定性を強化。
- **Electron デスクトップ版の設定永続化**:
  - ウィンドウサイズ・位置、最大化状態、選択言語をローカルに自動保存・復元する機能を追加。

### v1.1.3
- **「メッシュ単純化（Simplify）」機能の新設**:
  - Microsoft 3D Builder 同様に、選択した 3D モデルの頂点・ポリゴン面数を削減して軽量化する単純化機能を「編集」タブに追加。
  - スライダー（0〜6）による段階的な削減調整、リアルタイム 3D プレビュー、決定（確定・Undo対応）およびキャンセルに対応。
- **穴あき防止・水密性保護アルゴリズム**:
  - 位置座標による幾何学的頂点溶接（Position-only welding）により、同一座標にあるスプリット頂点を結合して面同士のトポロジー接続を復元。面の境界が裂けて穴が空く現象を防止。
  - 境界エッジの発生検知と安全最大削減可能数の事前探索を導入し、頂点が少ないモデルでも立体が破綻したり穴が空いたりする限度を超えないよう自動保護。

### v1.1.2
- **CI / GitHub Actions でのビルド安定化**:
  - `electron-builder` 実行スクリプトに `--publish never` を追加し、CI環境（GitHub Actions）で `GH_TOKEN` 未設定エラー（自動パブリッシュ試行）が発生してビルドが失敗する問題を修正。
  - `electron-builder.json` に `"publish": null` を追加し、暗黙的な自動リリース公開を無効化。

### v1.1.1
- **ペイント「X線 (透明)」機能の不具合修正**:
  - Three.js マテリアルの `needsUpdate = true` および透過時の `depthWrite = false` を正しく設定し、半透明表示が画面上に確実に反映されるよう修正。
  - オブジェクト選択変更時にペイントツールのカラー、ワイヤーフレーム、X線ボタンの状態が同期されるよう改善。
  - グループ階層やマルチマテリアルを持つオブジェクトに対しても全メッシュへ確実に適用するよう走査処理を強化。
- **ギズモ拡大縮小時の比率維持（Lock Aspect Ratio）対応**:
  - 「比率維持」チェックがONの状態で、3Dギズモ（TransformControls）のXYZ単一軸ハンドルをドラッグした際にもアスペクト比を維持して拡大縮小するよう改善。
  - XY, YZ, XZ 平面ハンドルおよび全軸ハンドルをドラッグした際にも、平面上のドラッグ距離・移動ベクトルに応じて3軸すべての立体比率が均等に維持されたままスムーズに拡大縮小するよう改善。
  - ギズモドラッグ操作完了時の Undo（元に戻す）履歴記録に対応。

### v1.1.0
- Electron によるマルチプラットフォーム デスクトップGUIアプリケーション対応（Windows / macOS / Linux）。
- GitHub Actions による全OSクロスプラットフォーム自動ビルド＆リリースワークフロー導入。
